💡 音訊設定與說明

1. Windows 預設播放裝置 需設為黑洞端點

請在 Windows 設定中，將「預設輸出裝置」改選為本軟體指定的黑洞端點。
這樣所有日常遊戲、影音與應用程式的聲音才會流入 DR_AudioRouter，由本軟體進行獨立混音、EQ 調校與 OBS 轉發。

2. 關於系統提示音（截圖聲、調整音量聲）

Windows 系統提示音（截圖喀擦聲、滑桿提示音、USB 插拔聲）是由系統核心直接合成，不具備獨立應用程式 PID，因此本軟體無法針對其進行捕捉與轉發，預設會被隔離於黑洞中而無法聽見。
此特性可確保您在競技遊戲、聽音辨位與實況轉播時，完全不受突發系統雜音干擾。

💡 轉送目標裝置說明

受限於系統硬體方向性，實體麥克風僅能讀取收音，無法作為轉送寫入目標。

• 🎙️ 供語音通話使用 (二選一)：
  1. Steam 內建驅動 (免額外安裝)：若電腦有安裝 Steam，可直接啟用其內建的 Steam Streaming Speakers / Microphone 當作轉送虛擬通道。
  2. 第三方虛擬音訊線路：亦可安裝知名虛擬驅動例如 VB-CABLE，建立專用的虛擬麥克風通道。

• 🎧 供 OBS 實況使用：可直接選擇下方任一閒置的播放裝置，並在 OBS 新增「音訊輸出擷取」接收。
